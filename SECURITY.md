# Security Policy

## Supported versions

Security fixes are applied to the latest released version. Older versions should be upgraded before requesting support.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues, pull requests, logs, or screenshots. Never include a merchant key, MID credential, authentication token, full card number, or unredacted transaction payload.

Use [GitHub private vulnerability reporting](https://github.com/cemililik/nicepay-paymentgateway-wordpress-plugin/security/advisories/new) to send:

- the affected version and environment;
- a concise impact assessment;
- reproducible steps or a minimal proof of concept;
- any suggested mitigation, if known.

The maintainers will acknowledge the report, validate its impact, and coordinate a fix and disclosure timeline through the private advisory. Please allow time for merchants to update before publishing technical details.

Payment disputes, credential provisioning, and NicePay merchant-account issues are not software vulnerabilities and should be handled through the payment provider's support channel.
